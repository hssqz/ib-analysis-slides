# 数字与口径检查

新内容含数据表、预测或中英文单位转换时读取。来源清单保留原值、原单位、输出值、换算公式和原页位置，区分原文事实、原文预测、自行计算和分析判断。

## 换算与总体

- 亿美元 → US$bn：除以10；亿元 → RMBbn：除以10；万台 → units：乘以10,000。数量级换算不是汇率换算，不更改币种。
- 例如 2,430 亿美元 = US$243bn；不是 US$2,430bn。一张图只使用一个明确单位。
- 合计仅累加互斥主项。工业总额包含汽车等子项，不能再次相加；零部件市场与整机市场也不能直接相加。
- 比例先核分子分母、时期与总体，再检查合计；因取整略偏100%与明显口径错误分开处理。

## 原文矛盾

1. 先检查原页、期间数、单位、预测状态和总体差异，不能仅依据转写文本擅自修正。
2. CAGR 使用 `(终值/初值)^(1/实际年数)-1`；不能把五个年份误作五个增长期间。
3. 若原文增速与端点不一致，可保留端点并把计算值明确标为 calculated / implied，记录公式和原文差异；也可不展示增速。不能静默替换原文。
4. 份额明显不闭合时不画环图或100%堆叠。不强行归一化来掩盖错误；金额同样未核实时不从金额反推“正确份额”。
5. 均价、目标售价、成本和报价是不同指标。未确认总体前分开呈现；不同年份、地区或机型不能拼成同一预测路径。
6. 仅重大、影响结论的差异进入页面，其余留在来源/问题记录；不要求每套演示都添加固定“数据冲突页”。无法支撑主结论时收敛范围或明确缺口。

## 图表与报表的数据契约

- 每组数字明确关系：互斥构成、子集、独立指标或不同分母。堆叠只累加互斥分项；子集用轮廓/注释，不再次加入柱高；独立指标另列，不借同一柱高表达。
- 端点有分类、期间只有总额时，允许端点堆叠/期间总量柱。没有分类的期间不插值编造。新内容没有这种数据结构时不强套选择性堆叠。
- 合计与显示分项可能因舍入产生差异；保留原值并说明精度，按源精度核对误差，不偷偷改其中一项使其相等。明显不闭合不能借“舍入”掩盖。
- 表格每列标明绝对额、同比/环比变化或比率变化。百分比用%，百分点用pp；负数括号、下限“+”、约数与目标范围保持原意。
- 横轴期间断点与纵轴截断是两件事；任一数量压缩都要明确标记，不能压短最大柱后仍暗示共用线性尺度。
- 期初+净流入+其他变动=期末；资产类别拆分与客户渠道拆分各自等于同一总量，两套拆分不能相加。净额与毛额的拨备位置、风险比率分母分别核对。
- 源表空白、破折号、N/A、N.M.不统一填0。复制数据前核对PDF/PPTX可见对应关系，碎片化PPTX文本不得自动当单元格真值。

## 经营驱动的归因层级

利润变动先在相同实体、期间与会计口径下建立收入—费用—拨备—税项的桥接，明确分析的是税前还是税后利润。标题、图题和正文的归因使用同一套证据粒度。

- 业务收入明细可计算该业务占总收入增量的贡献；归因到业务利润还需要对应业务费用/利润，或源材料明确披露的归因及其限定。
- 只有业务收入明细和分部合计费用时，将业务收入贡献与分部利润变化分别陈述；费用抵消项在分部层解释。不能把收入贡献比例换名为利润贡献比例。
- 有明确业务利润桥时，可计算该层级的净贡献；来源直接给出的定性驱动作为披露观点引用，不补造成本分摊。比较基数为零、负数或相互抵消时保留绝对变化及口径，避免百分比掩盖关系。

## 时间与标签归属

跨语言压缩表格时逐行核对“年份—状态—驱动—数值”的关联；相邻年份的解释不可因为更短而交换。图中外标签靠近对应扇区，或用引线/颜色明确的图例连接。两张图若共用终期构成，第二张需给出另一问题的证据（如基期占比与百分点变化），避免重复增加装饰。
