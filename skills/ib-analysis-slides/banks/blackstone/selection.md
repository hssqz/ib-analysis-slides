## What to preserve on content changes

1. Write a page decision record: question, claim, evidence areas, source locations, selected example, typography roles, chosen grouping geometry and known missing data.
2. Keep object/label/color relationships and mathematical encodings. Recompute geometry from the changed data. The example is not a fixed number of rows, mechanisms or years.
3. Adjust space to evidence and preserve readable role distinctions. A longer category label does not justify shrinking every title and footnote. Measure any selected group-label gap using the actual font.
4. Render the full page, inspect at native scale and compare the relevant theme example. An available complex chart is not a reason to use it without input evidence; rich input is not a reason to omit complementary evidence.
5. Record separately: source observed, example implemented, visual calibration, new-content local migration, independent triggering and independent pass. Stage-two evidence establishes the first three; selected later migration and independent tests are summarized in PROFILE.md, with the limitations above.
