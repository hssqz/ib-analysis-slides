## Dimensions and fonts

All but earnings use 720×540 source coordinates, displayed at 960×720. Earnings use 792×612, displayed at 960×741.82 (examples round to 742). Override the shared 960×540 default; resize the whole canvas uniformly. Footnotes are part of the canvas.

2025 source titles use Sanomat and body text Guardian Sans; these fonts are not bundled. The self-contained examples use Georgia and Arial with explicitly adapted wraps. Investor Day uses Georgia/Trebuchet MS, strategy uses Calibri/Georgia; the examples fall back to Arial/Georgia. These are system fonts, so portability of exact metrics is unverified. Do not claim exact brand-font reproduction or embed extracted report fonts without permission.

## Actual support boundary

Seven original, editable examples establish a starting point for five routed themes. They contain no private reports or brand images and rebuild using the Python standard library. Their arithmetic and actual browser renders are checked; selected local new-content migration has been reviewed, including a user-accepted six-page case. Three fresh tasks produced nine reviewed pages from ASML, Microsoft, IEA and JPM materials; subsequent tests covered a long group label, six financial periods, missing/zero/negative values and five-category/three-period allocations. Unaffected HTML and screenshots were preserved. These are selected tests, not blanket coverage.

Private development inspected 231 source pages and calibrated twelve whole pages against original PDFs (eight) or PPTX-derived renders (four). Some reference diagrams retain source vector geometry and some contain raster sub-assets; that calibration does **not** establish data-driven chart regeneration. The 2020 sensitivity grid's 208 displayed values and headers were recovered, but its exact underlying model is not recovered. Investment-size inputs for the reference bubble chart remain unavailable. Do not estimate them silently.

Other observed variants have contracts in selection.md but no blanket implementation/visual/migration pass. Validation is limited to the explicitly recorded cases; it does not certify every observed variant. Read sources.md for per-example limitations and the next validation conditions.
